LuminaLang

A strongly-typed compiled language. Write .lum source, compile to LLVM IR, and build a native executable with clang — no interpreter, no heavy runtime.

View on GitHub Get Started

Features

Strong Typing

Core types i32, f64, bool, string, plus dynamically-sized slices, all checked at compile time.

Control Flow

if / elif / else, while, for ... in, halt, skip.

Slices

[]i32, []f64, []bool, []string with literals, indexing, len and push/append.

LLVM Backend

Emits LLVM IR and links with clang: a single native executable that depends only on the OS runtime.

Standard Library

Fifteen modules written in LuminaLang itself, from math, strings and collections to encoding, json, os, time and fs.

Package Manager

photon: a package is just a git repository. Install with pho; photon.lock pins every commit for reproducible builds.

Syntax Overview

  1. Output: out "Hello, World!"
  2. Variables: let name: i32 = 42
  3. Conditionals: if score >= 90 { ... } elif ... { ... } else { ... }
  4. Loops: while i < 5 { ... }   for ch in "hello" { ... }
  5. Functions: fn add(a: i32, b: i32) i32 { back a + b }
  6. Slices: let xs: []i32 = [1, 2, 3]   xs = push(xs, 4)
  7. Imports: use math::sqrt

Packages (photon)

photon is the package manager. It is decentralised: a package is just a git repository, usually on GitHub, with no central registry. The command is pho.

# start a project and add a dependency
pho init myapp
pho add github:Lumina-hc/sample_package@v0.1.0
pho build

Packages ship source, a lumina.toml manifest, an optional declaration file (.lumi) and a precompiled .lumc library. Dependencies are resolved recursively and pinned in photon.lock.

Quick Start

  1. Install LLVM / clang and put it on your PATH (set LUMINA_CC to override).
  2. Install Go 1.21 or later (to build the compiler).
  3. Clone the repository: git clone https://github.com/Lumina-hc/LuminaLang.git
  4. Build the compiler: go build -o luminalang.exe .
  5. Compile a program: luminalang examples/test_bool_literals.lum
  6. Run it: .\test_bool_literals.exe
