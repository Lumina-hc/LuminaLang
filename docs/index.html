LuminaLang

A strongly-typed compiled language. Write .lum source, transpile to Go, build to a native executable.

View on GitHub Get Started

Features

Strong Typing

Three core types: i32, bool, string. Static type checking at compile time.

Control Flow

if / elif / else, while, for ... in, halt, skip.

Functions

Parameters, return values, and recursion. Clean, readable syntax.

Native Output

Compiles to a single native executable with zero runtime dependencies.

Standard Library

Math, bits, I/O, time, and OS modules with use imports.

Go Backend

Transpiles to Go, leveraging Go's fast compilation and cross-platform support.

Syntax Overview

  1. Output: out "Hello, World!"
  2. Variables: let name: i32 = 42
  3. Conditionals: if score >= 90 { ... } elif ... { ... } else { ... }
  4. Loops: while i < 5 { ... }   for ch in "hello" { ... }
  5. Functions: fn add(a: i32, b: i32) i32 { back a + b }
  6. Imports: use io::readline

Quick Start

  1. Install Go 1.21 or later.
  2. Clone the repository: git clone https://github.com/Lumina-hc/LuminaLang.git
  3. Build the compiler: go build -o luminalang.exe .
  4. Compile a program: luminalang examples/test_bool_literals.lum
  5. Run it: .\test_bool_literals.exe
